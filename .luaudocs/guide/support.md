# Support

Need help with Kohl's Admin, building an addon, or reporting a bug? Start with the guides below or ask in the community Discord.

## Documentation & Self-Help

Check whether your question is covered in the guides first:

- **[Installation](/guide/getting-started/installation)** & **[Configuration](/guide/getting-started/configuration)**: Setup instructions for Roblox Studio, roles, permissions, GamePasses, and groups.
- **[Using Commands](/guide/getting-started/using_commands)** & **[Using UIs](/guide/getting-started/using_uis)**: Command Bar shortcuts, target selectors (`@role`, `%team`, `$distance`, `$group`), and Dashboard tabs.
- **[Custom Commands](/guide/custom_commands)**, **[Addons & Hooks](/guide/addons)**, **[Custom Types](/guide/custom_types)**, & **[Themes & UI](/guide/themes_and_ui)**: Developer guides for extending Kohl's Admin.
- **[Troubleshooting](/guide/troubleshooting)**: Fixes for Studio `Sandboxed` capability errors, DataStores, HTTP requests, and custom command registration.
- **[API Reference](/api/)**: Luau type and function reference generated from the source code.

## Community Discord Server

Join the Discord server for real-time help from contributors and the support team:

- **Join Discord**: [discord.gg/kohl](https://discord.gg/kohl)
- **FAQ Channels**: Browse [FAQ Posts](https://discord.com/channels/694630328064671775/1298904707498246144) covering common setup and scripting questions.
- **Help & Support**: Ask questions about configuration, custom addons, or troubleshooting.
- **Announcements & Previews**: Follow new releases and upcoming changes.

## Bug Reports & Feature Requests

Found a bug or want to request a feature?

- **GitHub Issues**: [Open an issue on GitHub](https://github.com/kohls-admin/kohls-admin/issues/new/choose)
- **Discord**: Report issues or vote on community suggestions in the Discord server.
