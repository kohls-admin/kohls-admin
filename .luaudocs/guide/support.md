# Support

If you need help with Kohl's Admin (KA), have a question about custom addons, or want to report a bug, several community and documentation resources are available.

## Documentation & Self-Help

Before reaching out, check whether your question is covered in our guides:

- **[Installation](/guide/getting-started/installation)** & **[Configuration](/guide/getting-started/configuration)**: Step-by-step setup for Studio, roles, permissions, GamePasses, and groups.
- **[Using Commands](/guide/getting-started/using_commands)** & **[Using UIs](/guide/getting-started/using_uis)**: Command Bar shortcuts, target selectors (`@role`, `%team`, `$distance`, `$group`), and Dashboard features.
- **[Custom Commands](/guide/custom_commands)**, **[Addons & Hooks](/guide/addons)**, **[Custom Types](/guide/custom_types)**, & **[Themes & UI](/guide/themes_and_ui)**: Complete developer guides for extending Kohl's Admin.
- **[Troubleshooting](/guide/troubleshooting)**: Fixes for Studio `Sandboxed` capability errors, DataStores, HTTP Requests, and custom command registration.
- **[API Reference](/api/)**: Detailed Luau type and function reference generated directly from the source code.

## Community Discord Server

The fastest place to get real-time help is our community Discord server:

- **Join Discord**: [discord.gg/kohl](https://discord.gg/kohl)
- **FAQ Channels**: Browse [FAQ Posts](https://discord.com/channels/694630328064671775/1298904707498246144) written by the support team answering common questions.
- **Help & Support**: Ask questions about configuration, scripting addons, or troubleshooting.
- **Announcements & Previews**: Stay up to date with new releases and upcoming features.

## Bug Reports & Feature Requests

Found a bug in Kohl's Admin or have a feature request?

- **GitHub Issues**: [Open an issue on GitHub](https://github.com/kohls-admin/kohls-admin/issues/new/choose)
- **Discord**: Report issues or vote on community suggestions in the Discord server.
